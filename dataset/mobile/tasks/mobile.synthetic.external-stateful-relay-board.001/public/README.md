# Lantern Sequence Desk
Original standalone synthetic mobile web application. No dependencies or network services. Build with `sh build.sh`; the wrapper checks every ES module then copies the whitelist to dist without removing the mounted dist directory.

All ordinary client source is here: generic simulator/graph validation, complete board integration, ledger/waveform and lamp rendering, 12-frame editor, inbox attachment viewer, replay and local persistence. The designer inbox is a product import in browser storage (`lantern.provider.inbox`), supplied only in the prepared runtime. A raw local build truthfully starts empty. Do not replace the inbox with sample delivery data. Reload retains saved editions; a rebuild explicitly resets the prepared scene.

Finite engine: sample old Q and current inputs, evaluate a DAG, render outputs, then commit enabled D to next Q simultaneously. Zero-delay OR/AND/XOR/MASK gates; MASK(a,b)=a AND NOT b. Active-high one-tick memories. E0 is allowed even ticks, E1 allowed odd ticks. 12 rows numbered 0..11, unchecked input is 0. Pulse duration one checked frame. Reverse scrub replays from initial state. Play is display-only and stops at 11. All saved edits and notes are edition-local. The delivered guide and drawings give the approved integration, light-bank geometry and full product contract, reachable in Designer inbox before repair.

The ledger is a human-readable report, not a hidden test channel: labeled Inputs, Gates, Old, Next, Lights and Tick, with printed bit order. All rows are visible by scrolling. The stage is a 300:96 logical bank, centers x=50/150/250,y=48,r=22, named Flare/Wash/Pearl; on colors come from each edition, off #182334. This normalized public design permits different markup, simulation representations and page framing.
