# Mural Desk — standalone synthetic mobile web client

Original HTML/CSS/ES modules, no packages or network dependencies. Run `sh build.sh`; serve dist with any ordinary static server for local UI work. The prepared task runtime imports external Projection Office packets into its isolated browser profile. An ordinary local build starts with an empty inbox. There is no fixture file or endpoint in the coding workspace. The attachment viewer is ordinary public client code and works independently of mapping import.

Source map: geometry.js provides full matrix/projective/polygon operations; adapter.js imports a provider mapping; model.js uses it for clipping, inverse placement and receipt serialization; render.js paints artwork and marks; app.js owns editing, undo/cancel, storage and packet navigation; viewer.js renders received documents and images. All ordinary client files are editable except the fixed copy-to-dist build wrapper. No external data is bundled. Local storage holds imported inbox and saved plans separately. Ordinary reload retains both; task rebuilds explicitly reset the scene. Synthetic original artwork is external product input, not an upstream asset.
