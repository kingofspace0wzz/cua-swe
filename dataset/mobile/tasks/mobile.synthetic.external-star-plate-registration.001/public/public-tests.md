# Public acceptance contract
See the in-app Guide for geometry conventions, crop rules and measurement units.
1. Each edition: align the labeled overlay with every received disc; complete
   the name ledger and both-neighbour target offsets using its finder.
2. Draft shift / mounting / scale update the overlay and all reports live.
3. Reassign one disc; Undo and Cancel restore the previous draft/saved state.
4. Save the whole draft, including notes, then ordinary reload; neither edition
   may overwrite the other. Reset clears only the selected edition to its shipped
   received registration. Rebuild intentionally starts fresh.
5. Fit, 2×, 3×, scroll pan, sheet switching, overlay/observation-label toggles and
   the guide remain usable. Integration errors must leave the sheets accessible.
No incoming point lists or auto-pose discovery service are available. Reading
pixels algorithmically is not forbidden; generic repairs are legitimate.
