# Post-wheel reacquisition

Use the map's existing Help workflow in Native and Legacy. After the existing
wheel-zoom, held mouse moves and paused release, reacquire the then-visible
magenta dot without Reset, move to two held endpoints with a direction change,
and pause before release. The unchanged public allowances are 3 CSS pixels for
attachment/retention and 4 for Native/Legacy agreement. All earlier sequences
and checks are retained. Only the additional continuation is new.

The source is the admitted broken Mouse04 baseline, not a completed repair.
Gold and alternate are byte-identical inherited full repairs. incomplete.patch
is the original GPT6 source-only submission: individual mouse ownership is
repaired, but the shared CPU/rendered acquisition disagreement remains. Its
continued failure must be observed by the finite controls, not presumed.
